① 连接设置

🔌 连不上（CORS / Failed to fetch）？两种解法任选其一：
· 方案A（改 Ollama 配置）：先完全退出 Ollama，再设置环境变量后重启 ollama serve。 PowerShell：setx OLLAMA_ORIGINS "*"（永久）；CMD：set OLLAMA_ORIGINS=*（当前会话）。
· 方案B（不改配置，推荐）：在项目根目录执行 python -m http.server 8000， 再用浏览器打开 http://127.0.0.1:8000/tools/ocr_clean_gui.html —— 页面与 Ollama 同源（127.0.0.1）， 无需 OLLAMA_ORIGINS 也能连通。
· 模型名须与 ollama list 输出一致（默认 qwen2.5:local7b）。 可先点「测试连接」，它会列出本机所有模型名供对照。

② 载入批次文件

点「选择文件」选一个或多个 .json 批次文件即自动载入： 单选 = 单文件模式；多选（Ctrl/Shift 或拖入多个）= 按文件名排序、逐个文件自动判定模式并连续处理。

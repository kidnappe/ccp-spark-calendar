# 语义标注工具 · 使用说明

## 启动

双击 `tools/start_workshop.bat`，浏览器自动打开工具台（http://127.0.0.1:8001/tools/workshop.html），点顶部「🏷️ 语义标注」标签进入。

> 前提：本机需运行 Ollama（`ollama serve`），且已拉取模型 `qwen2.5:local7b`。仅使用规则打标时无需 Ollama。

---

## 功能概览

| 区块 | 作用 |
|------|------|
| ① 连接设置 | 选择 LLM 模型、测试 Ollama 连接 |
| ② 事件标签总览 | 查看 419 条事件的标注状态，支持筛选/搜索/批量勾选 |
| ③ 批量标注 | 规则打标（秒级）或 LLM 深度标注（逐条 10-20s） |
| ④ 保存与统计 | 将标签写入 events.json + 查看三维分布图 |
| ⑤ 计算相关事件 | 触发 build_similar 预计算 top-8 相关事件 |

---

## 操作流程

### 第一步：规则打标（推荐先做）

1. 点「全选」或按筛选条件勾选事件
2. 点「⚡ 规则打标（秒级）」
3. 结果立即显示在列表中：
   - **时期**（紫色标签）：100% 命中，按年份映射 11 个历史时期
   - **性质**（蓝色标签）：约 68% 命中，正则匹配 12 种事件类型
   - 红色标签 = 低置信度，需 LLM 补充

规则打标不消耗 LLM 资源，可反复执行，结果即时可保存。

### 第二步：LLM 深度标注（可选）

1. 筛选「低置信度」或「未标注」事件并勾选
2. 确认模型选择正确（默认 `qwen2.5:local7b`）
3. 点「🤖 LLM 深度标注」
4. 逐条调用本地模型，进度条实时更新，日志区显示结果
5. 随时可点「■ 停止」中断（已标注的不会丢失）

LLM 标注补充：
- **主题**（黄色标签）：8 选 1（军事/政治/经济/外交/思想文化/科技教育/社会民生/组织制度）
- **性质**：规则未命中时由 LLM 判断

> 全量 LLM 标注约需 2-3 小时（419 条 × 15-20s）。建议分批处理。

### 第三步：保存

点「💾 保存标签到 events.json」。写盘前自动备份到 `backups/` 目录。

### 第四步：计算相关事件

1. 确保标签已保存
2. 点「🔗 计算相关事件（build_similar）」
3. 等待约 2 秒（419 条 × 418 对稀疏向量点积）
4. 完成后，点工具台顶部「⚙️ 构建 index」重建页面数据

构建完成后刷新日历主页，事件详情弹窗的「相关事件」区块即生效。

## 筛选器说明

| 按钮 | 显示内容 |
|------|----------|
| 全部 | 所有事件 |
| 未标注 | 尚无标签或缺少主题的事件 |
| 低置信度 | nature 或 theme 置信度 < 0.7 的事件 |
| 已完成 | 三维标签齐全且置信度 ≥ 0.7 |

搜索框支持标题关键词实时过滤。

## 三维标签体系

```
时期 period（规则，年份映射）
├── 辛亥革命与北洋时期 (1911-1918)
├── 建党与大革命 (1919-1927)
├── 土地革命战争 (1927-1937)
├── 抗日战争 (1937-1945)
├── 解放战争 (1945-1949)
├── 社会主义改造 (1949-1956)
├── 全面建设社会主义 (1956-1966)
├── 文化大革命 (1966-1976)
├── 拨乱反正 (1976-1978)
├── 改革开放 (1978-2012)
└── 新时代 (2012-)

性质 nature（规则优先，LLM 兜底）
├── 会议 / 军事行动 / 条约协定 / 政策法令
├── 政治运动 / 机构创设 / 建设成就 / 人物逝世
└── 人事变动 / 群众事件 / 文告发表 / 外交活动 / 其他

主题 theme（LLM 8 选 1）
├── 军事 / 政治 / 经济 / 外交
└── 思想文化 / 科技教育 / 社会民生 / 组织制度
```

## 相关事件算法

得分公式（每对事件）：

```
score = 3.0 × 主题相同
      + 2.0 × 性质相同
      + 1.5 × 时期相同
      + 2.0 × TF-IDF 余弦相似度
      + 0.5 × 存在因果边
```

取 top-8 写入 `events.json` 的 `similar` 字段。

## 命令行等效操作

GUI 背后调用的脚本也可独立使用：

```bash
# 仅规则打标（全量，秒级）
python scripts/tag_events.py --rules-only

# 全量 LLM 打标（需 Ollama）
python scripts/tag_events.py

# 单条测试
python scripts/tag_events.py --key 1921-7-23

# 输出低置信度复核清单
python scripts/tag_events.py --review

# 计算相关事件
python scripts/build_similar.py

# 重建 index.html（使页面生效）
python scripts/build_data.py
```

---

## 注意事项

- 所有数据仅在本机处理，不联网（LLM 走本地 Ollama）
- 保存前自动备份 `events.json` + `causality.json` 到 `backups/`
- LLM 标注中断后重新打开页面，已保存的数据不会丢失；未保存的需重跑
- 修改标签后需重新「计算相关事件」+「构建 index」才能在日历页面看到效果

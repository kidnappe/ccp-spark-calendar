## 三、数据格式契约（务必遵守）

**事件主键（key）** = `"year-month-day"`，月/日**不补零**，例：`"1921-7-23"`、`"1949-10-1"`。

### `events.json`
```json
{
  "meta": { "total": 423, "from_book": 37, "source": "...", "key_rule": "year-month-day" },
  "events": [
    { "year": 1921, "month": 7, "day": 23, "title": "中共一大", "desc": "...", "cat": "party", "source": "..." }
  ]
}
```
（`cause`/`causedBy` 为可选注入字段，算法本身用 `year/month/day` 也能算 key。）

### `causality.json`
```json
{
  "edges": [
    {
      "from": "1911-10-10",
      "to": "1919-5-4",
      "tier": "verified",            // verified(实线/已证实) | inferred(虚线/推断) | background(弱/背景)
      "confidence": 0.9,             // 0~1，可选
      "evidence": "书中原句或转述",   // 溯源，可选但强烈建议
      "source": "《中国共产党简史》第一章"
    }
  ]
}
```

### 算法 `validate()` 校验规则（对照检查）
- 边必须有 `from`/`to`，且两者都必须是 `events.json` 里存在的 key —— 否则报 **error**。
- `tier` 缺省视为 `"inferred"`；`verified` 边**不允许成环**（成环报 error）。
- 时间方向应 `from ≤ to`（因不晚于果），倒置只报 **warning**，需人工确认。
- `confidence/evidence/source` 不参与校验，但用于溯源，建议填写。

## 五、建议的接手步骤（含可直接运行的骨架）

### 步骤 1：写 `build_causality.py` 生成 `causality.json`
```python
# -*- coding: utf-8 -*-
import json, os
# 自动定位项目根目录（脚本在 scripts/ 下时，取上一级）
ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
def load_pairs(p):
    return json.load(open(p, encoding="utf-8"))   # 内容是 [[from,to],...]

def main():
    edges = []
    # 已证实边
    for f, t in load_pairs(f"{ROOT}/.ocr/causal.json"):
        edges.append({"from": f, "to": t, "tier": "verified",
                      "confidence": 0.95, "evidence": "", "source": "星火日历CAUSAL"})
    # 推断边
    for f, t in load_pairs(f"{ROOT}/.ocr/causal_inferred.json"):
        edges.append({"from": f, "to": t, "tier": "inferred",
                      "confidence": 0.6, "evidence": "", "source": "星火日历CAUSAL_INFERRED"})
    # >>> 在此追加：37 条新书事件的因果边（手动从 book_causal.txt 取证后补） <<<
    json.dump({"edges": edges}, open(f"{ROOT}/causality.json", "w", encoding="utf-8"),
              ensure_ascii=False, indent=1)
    print("causality.json 边总数:", len(edges))

if __name__ == "__main__":
    main()
```

### 步骤 2：给新书事件补边
- 打开 `.ocr/book_causal.txt`，搜索新书事件日期（如 `1927-9-29` 三湾改编、`1935-1-7` 攻克遵义），把对应原文里的“因→果”关系写成边。
- 新书事件至少连一条 `from`（前因）和一条 `to`（后果），避免孤儿节点。
- 加进上面的 `edges` 列表，tier 据把握程度选 `verified` 或 `inferred`。

### 步骤 3：校验

```python
from causal_algorithm import load_project
g = load_project(ROOT)
for e in g.events:
    k = e["key"]
    e["causes"]   = [t for t, _ in g.adj.get(k, [])]
    e["causedBy"] = [f for f, _ in g.radj.get(k, [])]
json.dump({"meta":..., "events": g.events}, open("events.json","w",encoding="utf-8"), ensure_ascii=False, indent=1)
```

# 星火日历 · 项目概览

> 最后更新：2026-08-17
> 定位：一个纯前端、零依赖、单文件的交互式党史学习网页。

---

## 一、项目定位

一个**纯前端「党史事件日历」**工具，核心玩法是把中共党史上的重要事件按真实公历日期组织起来，
并提供因果脉络、时间轴、检索与筛选等增强视图。

- 左侧 12 个月份侧边栏切换
- 右侧按真实月历网格排布（周一开头）
- 每个日期格展示该月该日、不同年份发生的党史事件
- 点击日期弹窗看当日全部事件详情
- 因果网络图：可视化事件间的"因→果"脉络
- 关键词搜索、分类筛选（中共 / 国民党）、时间轴
- 内置"关于"页（更新日志 + 操作指南）
- 移动端自适应（布局、触控缩放/平移、去点按延迟）

一句话：**双击 `index.html` 即可运行的党史教育/查询工具，零部署成本。**

---

## 二、技术栈与架构

| 项 | 现状 |
|---|---|
| 运行环境 | 纯浏览器，零依赖、无构建 |
| 文件形态 | 单 HTML 文件，内联 CSS + 原生 JS |
| 数据来源 | **外部化**为 `events.json`（事件库）+ `causality.json`（因果链） |
| 数据注入 | 由 `scripts/build_data.py` 读取两个 JSON，重写 `index.html` 的数据块（构建期预计算 SVG 布局） |
| 状态管理 | 原生全局变量 + 少量模块函数 |
| 渲染方式 | 原生 DOM / SVG 操作，无框架 |

**数据流向（唯一事实源原则）：**

```
events.json  ┐
             ├─ scripts/build_data.py ─→ 重写 index.html 的 historyData / CAUSAL / CAUSAL_INFERRED / CAUSAL_LAYOUT
causality.json ┘
```

> ⚠️ **不要在 `index.html` 里手工维护数据块**——每次运行 `build_data.py` 都会被覆盖。
> 改数据请改 `events.json` / `causality.json` 后重跑脚本。

## 三、数据现状

- **事件库 `events.json`**：**423 条**事件（392 条基线 + 37 条从《中国共产党简史》补入，含具体日期的原库缺失事件）。
- **因果链 `causality.json`**：**460 条边**，其中 `verified`（已证实 / 实线）387 条、`background`（背景 / 虚线）73 条。
- **孤儿节点（4 个，非新书事件，无因果边）**：`1938-9-29` 六届六中全会 / `1940-3-30` 汪伪政权 / `1970-8-23` 九届二中全会 / `2006-10-11` 十六届六中全会。如需全连通可补边。
- **分类**：`cat="party"`（中共，红）381 条；`cat="kmt"`（国民党，蓝）42 条。
- 每条事件带 `source`（来源/出处）字段，便于溯源。

- 4 个孤儿节点尚未连入因果主干（见第三节）。
- 中共四大(1925-01)、中共五大(1927-04~05) 书中未给具体日，仍暂缓。
- OCR 原文摘录任务（用《中国共产党简史》扫描文本丰富弹窗描述）**暂停**，脚本 `.ocr/build_ocr_desc.py` 未最终落盘，仍有少量漏/误匹配。
- 因果图侧栏列表可考虑增加：类型图例、层级折叠、关键字定位、时间轴标记、详情快捷入口。
